# RALLY / 卓球試合ノート

卓球の試合スコアと振り返りを記録し、Markdownとしてコピーまたは保存するブラウザツールです。PC・iPhoneのブラウザで利用できます。外部ライブラリやビルド作業は不要です。

## 使い方

1. `index.html` をブラウザで開きます。
2. 「試合を追加」で試合を作成し、試合タブで記録を切り替えます。「一時保存」で入力内容を保存できます。入力内容は変更時にも自動保存されます。
3. シングルス／ダブルスを選び、対戦者名と試合形式を入力します。ダブルスでは各チーム2人目の名前欄が表示されます。
4. 試合中の位置に合わせて「自分が左／自分が右」を選びます。自分の名前は「藤本大助」が初期値です。
5. 各選手の利き腕・ラケット・フォア面ラバー・バック面ラバーを選びます。自分が「藤本大助」の場合は「左・シェーク・フォア面：裏・バック面：表」、対戦相手は「右・シェーク・フォア面：裏・バック面：裏」が初期値です。
6. 各セットの勝者を選び、敗者側の点数を入力します。勝者側は11点、デュースでは2点差となる点数が自動表示されます。
7. 感想・良かった点・悪かった点を記入し、「全試合のMarkdownを生成」を押します。保存済みの全試合をまとめて出力します。未完了の試合がある間は生成できません。
8. 生成されたテキストをコピーするか、`.md` ファイルとして保存します。

選べる形式は1・3・5・7セットマッチです。選択セット数の過半数を先取すると試合終了になります。登録した試合と入力中の記録はブラウザのローカルストレージに保存されます。

## GitHub Pagesで公開

GitHubアカウントが必要です。このツールはビルド不要の静的サイトなので、`index.html` を公開すれば動作します。以下はGitHubのWeb画面から公開する手順です。

### 1. リポジトリを作成する

1. [GitHub](https://github.com/) にサインインし、画面右上の **＋ → New repository** を選びます。
2. **Repository name** に任意の名前（例：`table-tennis-match-notes`）を入力します。
3. **Public** を選びます。無料で公開する場合はPublicリポジトリが簡単です。リポジトリをPublicにすると、ソースコードも誰でも閲覧できます。
4. **Create repository** を押します。

### 2. ファイルをアップロードする

1. 作成したリポジトリを開き、**Add file → Upload files** を選びます。
2. このフォルダーにある `index.html`、`apple-touch-icon.png`、`README.md` を選択するか、画面にドラッグ＆ドロップします。
3. 3つのファイルがリポジトリの一番上（ルート）に表示されていることを確認します。`index.html` とアイコン画像がサブフォルダーの中に入らないようにしてください。
4. **Commit changes** を押し、変更を保存します。ブランチ名は通常 `main` です。

### 3. GitHub Pagesを設定する

1. リポジトリの **Settings** を開きます。
2. 左側の **Code and automation → Pages** を選びます。
3. **Build and deployment** の **Source** で **Deploy from a branch** を選択します。
4. **Branch** で `main`（ファイルを保存したブランチ）を選び、フォルダーは **/(root)** にします。
5. **Save** を押します。

### 4. 公開を確認する

1. Pages設定画面に表示される公開URLを開きます。通常のURLは `https://<ユーザー名>.github.io/<リポジトリ名>/` です。
2. 設定直後は公開処理に数分かかることがあります。表示されない場合は少し待ってから再読み込みし、リポジトリの **Actions** でPagesのデプロイが完了しているか確認してください。
3. 404になる場合は、`index.html` が選択したブランチのルートにあることと、Pagesのブランチ・フォルダー設定を確認してください。

### 公開後に内容を更新する

`index.html` や `README.md` を変更したら、同じリポジトリのルートにアップロードして変更をCommitします。PagesはCommitを検知して自動的に再公開します。反映まで数分かかる場合があります。

### 記録データについて

試合記録は、利用しているブラウザのローカルストレージに保存され、GitHubには送信されません。ただし、GitHub上のリポジトリがPublicの場合、公開ファイルに書き込んだ内容は誰でも見られます。試合のメモなど個人情報はHTMLやREADMEに書かないでください。

ローカルストレージの記録はブラウザと公開URLごとに保存され、他の端末やブラウザとは同期されません。ローカルで開いていたときの記録も、GitHub PagesのURLには引き継がれません。
